# PMA Building Palace data: sources and licence notes

`pma_plan.json` is generated by `docs/building-palace/build_pma_plan.py` from public sources. Everything is sourced (a `src` id with its licence) or assumed (confidence 0-1 and a basis).

| source | use | licence / terms |
|---|---|---|
| The Architectural Forum, July 1928, plan plates (Internet Archive, Boston Public Library scan) | walls, rooms, doors, stairs, columns, as built in 1928 | public domain (US 1928) |
| OpenStreetMap way 28533972 | exterior shell outline; registration of the 1928 plates | ODbL 1.0, (c) OpenStreetMap contributors. Attribution is in the plan and the blueprint footer. A published database derived from it stays ODbL; replace by the City of Philadelphia footprint layer to drop the obligation |
| PMA visitor map, PMA event floor plans (2018), PMA press releases 2021, PMA library guide | gallery numbers, levels, collection areas, published dimensions, installation names (facts only) | (c) Philadelphia Museum of Art. Facts only; never traced, copied or redistributed |
| USGS 3DEP | grade for the terrace and steps | public domain |
| Wikimedia Commons photographs of the Great Stair Hall | viewed for height/material estimates | CC BY-SA / CC BY, not redistributed |
| Wikimedia Commons reproductions of 4 paintings (Peale, Tanner, Monet, Van der Weyden) (`pma_art.json`) | 512 px JPEGs in `alto/assets/bldg/pma/`, hosted under `/bart/` | public domain (artists d. 1464-1937; Commons licence label read 2026-10-19) |

Never used: images of works by Duchamp, Brancusi, Rivera, Calder or living artists (title cards only, no image); PMA photographs; the visitor map or event plans as drawings.
Withheld on purpose: the Leyster image (gallery 364 is confirmed but no traced room contains its label point), the Gross Clinic image (its gallery is 255 or 211 depending on the source), works whose gallery number is unconfirmed (Large Bathers, Sunflowers, Prometheus Bound), the Large Glass (PMA record: not on view).

Levels are the visitor map's G, 1, 2, 3. The 1928 sheets are basement = 1, first floor = 2, second floor = 3; G is not on them.
